## 실제 실행에서 발견한 추가 결함

합성 영어 음성으로 앱의 전체 자막 대기열을 실행했을 때 첫 문장만 인식되는 문제를 재현했습니다. 16kHz 음성 추출의 8kHz low-pass 필터에서 후반 진폭이 증가하는 것을 확인했습니다. 불필요한 Nyquist 경계 필터를 제거하고 80Hz high-pass와 리샘플링은 유지했습니다. 실제 FFmpeg로 16kHz·48kHz AAC를 추출하여 전체 길이와 초별 RMS를 확인하는 회귀 검사를 추가했습니다. 수정 전 16kHz 사례는 실패하고 수정 후 두 사례가 통과합니다.

## 통합 검증

공식 Windows CI에서 단위·통합 테스트 594개가 통과한 뒤 배포 검증 도구 테스트 3개가 실패했습니다. Windows PowerShell이 오류 메시지를 단어 중간에서도 자동 줄바꿈하는 차이였으며, 오류 종료 코드와 거부 사유는 기대값과 일치했습니다. 짧은 경로에서 같은 실패를 재현한 후 테스트의 표시용 줄바꿈만 제거하여 비교하도록 수정했습니다. 종료 코드·메시지·해시 검증은 유지했고 검증 도구 자체는 바꾸지 않았습니다. 통합 후 존재하는 카테고리 필드와 어긋난 Stash 안내도 기존 카테고리를 보존하는 실제 동작에 맞췄습니다.

최종 배포 파일의 검사 결과, 빌드 커밋, 파일 서명 상태 및 실기기 범위는 같은 릴리스의 `VERIFICATION.md`와 `SHA256SUMS.txt`에 기록합니다. 앱 소스와 미디어 대응 소스도 함께 제공합니다.

검증은 임시 영상·별도 앱 데이터로 수행하며 기존 사용자 라이브러리를 수정하지 않습니다. 실제 GPU 검사는 Microsoft Zira로 새로 만든 영어 음성과 로컬 base 모델을 사용하고 번역을 끕니다. 모델 캐시의 크기와 SHA-256을 확인하며 사용자 영상이나 비공개 자료를 릴리스에 포함하지 않습니다.

공개 이력 검사는 공유 작업 공간의 다른 브랜치가 섞이지 않도록 해당 배포 브랜치만 복제하여 수행합니다. 기존 공개 데모 영상과 사설 IP 거부용 합성 테스트의 경고는 출처·해시·용도를 검토합니다. 검사 규칙을 완화하거나 테스트 전체를 예외 처리하지 않습니다.

## 지원 범위와 남은 검증 범위

- Windows 10/11 x64용입니다. 스트리밍·모바일·NAS 서버·macOS·Windows ARM·VSR·SVP 신규 기능은 구현되지 않았으며 도입 검토 문서를 제공합니다.
- Stash는 사용자가 설정한 서버의 후보에서 제목·메모·태그를 확인 후 가져오는 범위입니다. 이미지·인물·장르 전용 필드와 다른 제공자는 후속 범위입니다.
- 추천·문장 조건 검색은 로컬 규칙 기반이며 외부 LLM 검색이 아닙니다.
- 실행 의존성의 알려진 취약점은 검사 당시 0건입니다. 개발 의존성의 moderate 9건은 기존 main과 동일한 sprintf-js 경로이며 high/critical은 없습니다.
- 별도의 깨끗한 Windows VM에서 최초 WSL 설치와 재부팅, 모든 GPU·코덱·언어의 호환성을 확인한 결과로 해석하지 않습니다. 온라인 번역·외부 Stash 실서버는 테스트 대역 기반 검증과 구분합니다.
