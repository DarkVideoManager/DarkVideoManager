# 0.3.3 PR 검토 기록

검토일: 2026-10-18 KST. 대상은 모바일 웹 개선 [PR #73](https://github.com/DarkVideoManager/DarkVideoManager/pull/73), 전체화면 3단계 전환 [PR #74](https://github.com/DarkVideoManager/DarkVideoManager/pull/74), 자막 병렬 실행 [PR #75](https://github.com/DarkVideoManager/DarkVideoManager/pull/75)입니다.

## 모바일 웹

터치 메뉴의 펼침 상태, 작은 화면의 영상 선택·목록 복귀, 인라인 재생, 키보드 단축키와 터치 버튼의 공존을 검토했습니다. 웹 전용 CSS와 문구 변환이 설치형 앱에 적용되지 않는지, 데모의 공개 샘플·다운로드 링크와 기존 저장 기록이 보존되는지도 확인했습니다.

## 전체화면

영상만 표시 → 하이라이트 위치 표시 → 일반 화면의 전환과 Esc 해제, 영상의 DOM·재생 위치·일시정지 상태 유지, 자동으로 숨는 전환 버튼의 포인터·키보드 접근, 하이라이트 탐색과 오류 표시를 검토했습니다. 모바일 데모의 영상 높이 지정과 전체화면 레이아웃이 겹치는 부분도 함께 확인했습니다.

## 자막 병렬 실행

실행 수의 범위·저장·복원, 같은 라이브러리의 다른 영상 실행, 같은 영상의 중복 요청 차단, 작업별 진행률·중단 신호와 임시 경로 분리를 검토했습니다. 일시정지·삭제·취소·실패 시 다른 작업을 보존하고, 실제 작업 정리가 끝난 뒤 다음 작업을 시작하는지 확인했습니다.

앱 종료와 대기열 저장 실패는 모든 실행 작업에 적용되며, 저장 복구는 전체 정리를 기다립니다. 가져오기·닫기 같은 배타적인 라이브러리 작업의 보호와, 다른 작업이 사용 중인 모델 캐시를 재사용하기 전의 크기·SHA-256 확인도 검토했습니다.

## 통합과 검증 범위

세 PR의 기능 코드는 함께 통합되었습니다. 변경 이력의 같은 위치를 수정한 충돌은 0.3.3 항목으로 정리하고 각 변경 내용을 보존했습니다. 버전과 다운로드·검토 안내를 함께 갱신합니다.

각 PR의 GitHub 검사 성공을 확인했으며, 통합 소스와 실제 배포 파일의 최종 검사 결과·실행 기록·파일 해시는 릴리스에 첨부하는 `VERIFICATION.md`와 `SHA256SUMS.txt`에 기록합니다. 브라우저 데모는 실제 GPU 음성 인식을 실행하지 않습니다. 자동 검사만으로 실제 GPU 병렬 성능, 모든 장치·코덱·언어, 새 Windows의 설치 마법사나 WSL 최초 설치·재시작을 검증한 것으로 해석하지 않습니다.
