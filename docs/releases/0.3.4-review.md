## 자동 업데이트

설치형·포터블·개발 실행의 구분, 공개 정식 릴리스로 고정된 업데이트 주소, 자동 확인 설정의 저장, 실패 후 재시도와 업데이트 알림을 검토했습니다. 설치는 사용자가 재시작을 선택한 뒤 자막·영상 변환 작업 저장과 기존 종료 정리를 마쳤을 때만 진행합니다. 정리 실패 시 설치하지 않습니다.

실제 업데이터와 별도 localhost 서버로 정상 다운로드·SHA-512 확인, 손상 파일 거부, 다운그레이드 거부를 검사했습니다. 패키징 도구는 버전·파일명·크기·해시·blockmap과 내부 업데이트 주소를 확인합니다. 이 검사는 설치 프로그램을 실행하지 않으며, 실제 Windows 설치 교체와 재시작을 검증한 것으로 해석하지 않습니다.

## 라이브러리 화면

1255px 화면에서 재현한 버튼 줄바꿈을 수정했습니다. 버튼의 너비와 한 줄 표시를 유지하고 작은 창에서는 설명과 버튼을 세로로 배치합니다. 1255·1000·760·560px와 글자 크기 150%에서 확인했으며 기존 라이브러리 생성·폴더 선택·취소 검사를 통과했습니다.

## 자막 인코딩

[#76](https://github.com/DarkVideoManager/DarkVideoManager/issues/76)의 실행 코드 수정은 이미 0.3.3에 포함되어 있습니다. 이번 PR은 CP949 진단 모델 경로와 UTF-8 자막 본문을 구분하는 회귀 검사, 원어 SRT 저장과 번역 재개 검사를 보강합니다. 중요한 메타데이터·시간·본문의 손상은 계속 거부합니다.

Windows Vulkan 브리지 검사 28개와 WSL Python 전체 검사 142개를 통과했습니다. 검증된 0.3.3 네이티브 런타임으로 한글 경로의 base 모델과 합성 영어 음성을 검사했으며, 원어 SRT 저장을 확인했습니다. medium은 회귀 자료로 확인했고 실제 번역 서비스는 실행하지 않았습니다.

## 통합과 배포 검사

세 PR의 원본 커밋에서 GitHub 자동 검사가 모두 성공한 것을 확인한 뒤 병합했습니다. 통합 소스의 버전·변경 이력·다운로드 안내를 0.3.4로 정리합니다. 통합된 소스의 최종 자동 검사와 실제 배포 파일·GPU 런타임·업데이트 파일의 검증 결과는 릴리스의 [VERIFICATION.md](https://github.com/DarkVideoManager/DarkVideoManager/releases/download/v0.3.4/VERIFICATION.md), 각 파일의 해시는 [SHA256SUMS.txt](https://github.com/DarkVideoManager/DarkVideoManager/releases/download/v0.3.4/SHA256SUMS.txt)에 기록합니다.

추가 통합 검사에서 브라우저 데모의 업데이트 API 누락을 발견했습니다. 데모는 해당 요청에 Windows 전용 기능이라는 오류를 반환하고 업데이트 이벤트 구독은 안전하게 해제할 수 있도록 보완했습니다. 기존 검사로 모든 데스크톱 API의 존재를 확인하고 업데이트 요청이 네트워크·설치·저장 데이터 변경을 일으키지 않는지도 검사합니다.

배포본은 Windows x64이며 코드 서명이 없습니다. 모든 GPU·언어·장시간 영상·보안 프로그램, 깨끗한 Windows의 설치 마법사와 설치 교체·재시작 검증은 별도입니다.
