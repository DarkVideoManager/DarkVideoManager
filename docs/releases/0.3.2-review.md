# 0.3.2 PR 검토 기록

검토일: 2026-10-16 KST. 대상은 기존 SRT 인식 개선 [PR #67](https://github.com/DarkVideoManager/DarkVideoManager/pull/67)과 재생·영상 정보·라이브러리 개선 [PR #68](https://github.com/DarkVideoManager/DarkVideoManager/pull/68)입니다.

## 기존 SRT

정확한 파일명·언어 표시·가장 가까운 영상 이름의 우선순위, 유사한 영상에 다른 자막이 연결되지 않는지, 추가·삭제 시 기존 트랙 ID·인코딩·내장 자막이 보존되는지 검토했습니다. 읽기 전용·제거한 영상·오프라인 경로·진행 중인 작업·취소 처리 중에는 기존 기록을 보존하는지도 확인했습니다. 별도 검토자가 관련 43개 검사를 재실행했으며 수정이 필요한 새 결함은 발견하지 못했습니다.

두 PR을 함께 적용할 때 검사 스크립트가 새 라이브러리 목록과 기존 관리 카드의 같은 이름을 구분하도록 범위를 좁혔습니다. 자막 탐색은 기존 버튼과 새 탭 역할 양쪽에서 검사할 수 있도록 했습니다.

## 재생·영상 정보·라이브러리

A-B 반복의 유효 구간·실제 재생 시계·일시정지·탐색·영상 및 재생 소스 변경 시 초기화, 재생 전 FPS와 알 수 없는 값의 처리, 상세 탭의 접근성과 자막 생성 작업 보존을 검토했습니다. 여러 폴더의 검색이 모두 성공한 뒤 반영하는지, 전환 실패 시 기존 화면을 유지하는지, 재생 세션과 진행 중인 작업이 원래 라이브러리에 귀속되는지도 확인했습니다.

현재 라이브러리를 삭제하는 동안 다른 라이브러리로 전환하면 삭제 완료 콜백이 이전 선택을 기준으로 새 선택까지 지우는 문제를 재현했습니다. 콜백에서 현재 선택을 다시 확인하도록 수정하고, 삭제 중 전환 성공·전환 실패·다른 라이브러리 삭제의 회귀 검사 3개를 추가했습니다. 수정 전 실패를 확인한 뒤 A-B·상세 탭·라이브러리 화면 검사 17개와 관련 단위 검사 71개가 통과했습니다. 영상 파일이나 새 라이브러리 DB가 삭제되는 문제는 아니었습니다.

## 배포 전 검사

두 변경을 합친 소스의 단위·통합 검사 664개와 타입 검사·빌드가 통과했습니다. 기존 선택 검사 1개는 필요한 선택적 런타임이 없어 건너뛰었습니다. PR #68의 전체 화면 검사 194개와 실제 Electron SRT 4개·라이브러리 5개 검사 그룹도 통과했습니다. 최종 배포 파일의 검사 결과와 파일 해시는 릴리스의 `VERIFICATION.md` 및 `SHA256SUMS.txt`에 따로 기록합니다.

PR #67의 최초 GitHub 검사에서는 테스트용 PowerShell 실행이 15초 제한 직후 실패했습니다. 같은 제품 코드로 PR #68과 로컬 검사는 통과했습니다. 원래 예외 처리로 정확한 시간 초과 코드까지 확인하지 못했으나 첫 실행 지연에 대한 여유가 부족한 것으로 판단하여, 확인 항목을 유지하고 해당 테스트의 대기 시간만 보완했습니다. 관련 검사 54개가 통과했으며 실제 WSL 설치나 제품의 시간 제한은 변경하지 않았습니다.

## 지원 범위

A-B 반복은 인앱 플레이어에서 지원하며 외부 mpv·VLC·FFplay는 자체 반복 조작을 사용합니다. FPS는 수집된 평균값입니다. 실제 이동식 저장장치, 모든 코덱·GPU·언어, 깨끗한 Windows의 설치 마법사 및 WSL 최초 설치·재부팅은 이번 변경의 자동 검사 범위가 아닙니다. 배포 파일의 코드 서명 여부와 검사 범위는 최종 검증 기록을 확인하세요.
