# 대표 썸네일 선택과 다시 생성

라이브러리에서 영상 카드를 한 번 누른 뒤 **상세 정보 → 정보 → 대표 썸네일 선택**에서 후보를 볼 수 있습니다. 자동 생성은 영상의 10·30·50·70·90% 지점에서 최대 5개를 시도하며, 디코딩 결과에 따라 후보가 더 적을 수 있습니다. 플레이어에서 직접 캡처한 장면이 있으면 함께 표시합니다. 후보 수를 항상 5개라고 가정하지 않습니다.

원하는 후보를 누르면 **현재 대표** 표시가 옮겨지고 카드·상세 이미지가 갱신됩니다. 선택은 라이브러리 DB에 즉시 저장되므로 앱을 다시 실행한 뒤에도 유지됩니다. 원본 영상과 다른 후보 파일은 선택만으로 바꾸지 않습니다. 저장 실패 시 오류가 표시되며 이전 대표를 유지합니다. 작업 종료 후 다시 선택할 수 있습니다.

**다시 생성**은 선택과 다른 작업입니다. 원본 영상에서 새 후보를 추출해 기존 후보를 교체하고 가운데 후보를 새 대표로 정합니다. 직접 캡처한 후보와 기존 대표 선택도 교체되므로, 생성이 끝나면 원하는 후보를 다시 선택하세요. 생성 중에는 대표 선택이 잠기고 진행 상태·중단 버튼을 볼 수 있습니다.

- **후보 없음:** 원본 영상 위치를 확인하고 **다시 생성**을 누릅니다.
- **후보 목록 조회 실패:** **후보 다시 불러오기**를 누릅니다. 조회 오류를 후보 없음으로 표시하지 않습니다.
- **이미지를 읽지 못함:** 해당 후보는 선택할 수 없습니다. 파일이 이동·삭제되지 않았는지 확인하고 **다시 생성**합니다.
- **생성 실패·취소:** 작업 상태의 오류를 확인한 뒤 원본 영상의 접근 가능 여부를 확인하고 **다시 생성**합니다. 생성 실패는 기존 후보를 일괄 삭제하기 전에 처리됩니다.
- **제거한 영상:** 원본 파일을 복원하고 **목록 복구**한 뒤 생성·선택합니다.

대체 썸네일을 켠 경우 카드에는 보호용 이미지가 보일 수 있습니다. [화면 보호 안내](library-discovery-and-privacy.md)를 참고하세요.
