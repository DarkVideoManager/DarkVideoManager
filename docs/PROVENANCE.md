# 코드와 배포 자산의 출처

## 프로젝트 코드와 아이콘

DarkVideoManager의 자체 코드와 `resources/icon.ico`는 루트의 [MIT 라이선스](../LICENSE)를 따릅니다.
프로젝트 소유자는 2026-10-13 공개 준비 과정에서 복구에 사용한 원본 프로그램과 현재 아이콘 모두를
오픈소스로 공개할 권한이 있음을 확인했습니다. 이는 소유자가 제공한 권리 확인 기록입니다.

일부 화면과 서비스는 DarkVideoManager 0.1.0의 배포본에서 동작을 재구성했습니다.
원본 `app.asar`의 SHA-256은
`b8917658981deebce3912c9e40aed64a84a393630d18efbcd94eb27ac3a9bbc7`입니다.
복구 이력은 [복구 문서](restoration.md)에 남깁니다. 이 문서는 현재 공개본의 설치 지침을 대신하지 않습니다.

공개 저장소는 개인 정보가 포함된 개발 이력을 제외한 소스 스냅샷으로 시작합니다.

## 외부 구성요소

React 등 외부 라이브러리는 npm 패키지로 사용하며, 원래 저작권과 개별 라이선스를 유지합니다.
프로젝트의 MIT 라이선스는 외부 구성요소를 MIT로 재라이선스한다는 의미가 아닙니다.
FFmpeg, FFprobe, Electron, SQLite, 음성 인식 런타임 및 다운로드 모델의 조건은 별도로 확인합니다.

사용자의 영상, 자막, 라이브러리 데이터, API 키, 설정 백업은 프로젝트의 공개 자산에 포함하지 않습니다.
테스트에 필요한 영상과 데이터는 테스트가 임시 폴더에서 생성합니다.
