# 추천 탐색과 화면 보호

## 내 라이브러리에서 추천받기

라이브러리를 연 뒤 상단 **추천 탐색**을 선택합니다. 현재 라이브러리의 등록 영상만 찾으며 외부 콘텐츠를 검색하지 않습니다.

- 영상 옆 **즐겨찾기 등록 / 해제**로 관심 영상을 지정합니다. 이 즐겨찾기는 영상 단위이며 기존 하이라이트와 별개입니다.
- **선호 태그·인물**에 쉼표로 구분한 이름을 저장합니다. 영상의 태그와 비교하므로 인물 이름도 먼저 태그로 등록되어 있어야 합니다. 얼굴 인식은 하지 않습니다.
- 선호 태그, 즐겨찾기, 4점 이상 별점, 시청 이력과 겹치는 태그를 이용해 순서를 정합니다. 각 영상에 추천 이유를 표시합니다. 근거가 없으면 파일명 순으로 표시합니다. 추천 품질을 측정한 결과는 없습니다.
- 즐겨찾기와 선호 태그는 라이브러리별로 PC의 설정 파일에 보관합니다. 선호 태그를 지우거나 즐겨찾기를 해제할 수 있습니다. 별점·시청 기록은 기존 라이브러리 DB를 사용합니다.

### 조건을 문장으로 입력하기

예: **아직 안 본 20분 이하 축구**, **즐겨찾기 자막 있는**, **별점 4점 이상 최근 본**.

지원하는 표현은 `미시청` / `아직 안 본` / `보지 않은`, `즐겨찾기`, `자막 있는` / `자막 있음`, `최근 본`, 숫자와 `분 이하·미만·이상·초과`, `별점 0~5점 이상`입니다. 여러 조건은 모두 만족해야 합니다. 재생 시간이 없는 영상은 시간 조건에 포함하지 않습니다.

나머지 단어는 제목·파일명·메모·태그에서 모두 찾습니다. 예를 들어 `축구 결승`은 두 단어를 모두 포함해야 합니다. 인식한 조건과 남은 검색어를 결과 위에 표시합니다. 자유 문장 전체를 이해하는 AI 검색은 아니며 모르는 표현을 임의로 해석하지 않습니다. 결과가 없으면 표시된 조건을 확인하고 검색어를 줄이세요.

삭제·목록 제외한 영상은 결과와 추천 근거에서 제외합니다. 전체 등록 영상을 대상으로 조건을 적용하고 결과는 50개씩 표시합니다. 검색어·선호 정보·시청 이력을 외부 서비스로 보내지 않습니다.

## 대체 썸네일

**설정 → 화면 보호 → 목록 썸네일을 대체 화면으로 가리기**를 켜고 **화면 보호 설정 저장**을 누릅니다. 기본값은 꺼짐입니다. 사용하면 원본 대신 중립적인 `썸네일 가림` 화면을 보여 줍니다. 저장 전에는 적용하지 않으며 저장 실패 시 기존 설정을 유지합니다.

**마우스를 올리거나 키보드로 선택하면 원본 표시**는 별도 선택입니다. 켜져 있으면 썸네일에 마우스를 올리거나 카드에 키보드 초점을 두었을 때만 원본을 보여 줍니다. 꺼두면 목록의 원본 이미지를 계속 가립니다. 이 설정은 제목·메모·상세 패널 이미지·실제 재생 화면을 숨기지는 않습니다.

## 긴급 탈출

**설정 → 화면 보호 → 긴급 탈출 후 화면**에서 아래 동작을 선택해 저장합니다.

| 선택                           | 동작                                                               |
| ------------------------------ | ------------------------------------------------------------------ |
| 앱 창 닫기                     | 기존 종료 흐름 사용. 미완료 작업이 있으면 트레이에서 계속됩니다.   |
| 가림 화면 표시                 | 재생 화면을 비우고 앱에 중립적인 가림 화면을 표시합니다.           |
| 가림 화면과 지정 웹페이지 열기 | 가림 화면을 유지하면서 저장한 HTTPS 주소를 기본 브라우저로 엽니다. |

앱에 초점이 있을 때 **Ctrl+Shift+H**, 상단 **화면 숨기기**, 목록·자막 대기열의 **Esc**로 실행합니다. 플레이어의 Esc는 기존처럼 목록으로 돌아갑니다. 입력창·일반 대화상자의 Esc는 원래 조작을 유지하며 Ctrl+Shift+H는 대화상자에서도 작동합니다. 운영체제 전체의 전역 단축키는 아닙니다.

인앱 영상을 일시정지하고 화면에서 제거한 다음 앱이 직접 실행해 추적하는 외부 플레이어의 종료를 요청합니다. VLC는 앱이 추적할 수 있는 별도 인스턴스로 실행합니다. 이미 따로 실행한 외부 플레이어는 통제하지 않으므로 해당 창은 직접 확인해야 합니다. 자막 생성과 변환 대기열은 계속됩니다.

웹 주소는 사용자 이름·암호가 없는 HTTPS 주소만 허용합니다. 저장 자체로 접속하지 않으며 탈출을 실행할 때 접속합니다. 해당 사이트와 브라우저에는 일반 웹 접속 기록이 남을 수 있습니다. 웹페이지 열기나 외부 재생 종료가 실패해도 가림 화면을 유지하고 오류를 표시합니다. **화면 다시 열기**를 명시적으로 누른 뒤 앱을 다시 사용합니다.

대체 썸네일과 가림 화면은 화면 표시 기능입니다. 원본·캐시·최근 사용 기록·운영체제 미리보기를 삭제하거나 암호화하는 기능은 아닙니다.
