# 파일명 정리와 정확한 중복 후보

라이브러리를 연 뒤 상단의 **파일 정리**를 선택합니다. 현재 라이브러리에 등록된 원본 영상만 대상으로 하며, 목록에서 제거한 항목은 제외합니다.

## 파일명 정리

1. **제거할 접두어**에 파일명 앞의 문자열을 입력합니다. 예를 들어 `[광고] `를 입력하면 `[광고] 영상.mp4`의 이름을 `영상.mp4`로 제안합니다.
2. **미리보기**에서 원래 경로와 변경할 경로를 확인합니다. 접두어는 대소문자까지 정확히 일치할 때 한 번 제거하며, 남은 이름 양끝의 공백을 정리합니다. 확장자는 유지하고 정규식은 사용하지 않습니다.
3. 변경할 항목을 선택하고 **선택한 이름 변경 → 확인 후 변경**을 누릅니다. 한 번에 최대 500개를 미리보기할 수 있습니다. 나머지는 적용 후 다시 미리보기합니다.

영상과 이름이 연결된 등록 외부 자막도 미리보기에 함께 표시하고 같은 묶음으로 변경합니다. 영상 ID, 제목, 태그, 평점, 메모, 하이라이트와 재생 기록은 유지합니다. 폴더에 나중에 추가한 미등록 자막이나 연결 방식이 불분명한 자막이 있으면 해당 영상을 제외합니다. 라이브러리를 새로고침하고 자막 연결을 확인한 뒤 다시 미리보기합니다.

다음 항목은 변경하지 않습니다.

- 앱에서 재생 중이거나 앱이 실행한 외부 플레이어에서 사용 중인 원본
- 대기·일시정지를 포함한 미완료 자막 또는 재생 변환 작업의 원본
- 같은 라이브러리의 다른 영상이나 다른 등록 라이브러리와 공유하는 파일, 다른 항목이 이미 등록한 변경 대상 경로
- 누락된 파일, 파일 링크, 변경할 이름과 충돌하는 파일, Windows에서 사용할 수 없는 이름
- 미리보기 이후 내용·위치·자막 연결이 달라진 항목 또는 읽기 전용 라이브러리

미리보기는 10분간 유효하며 한 번만 적용할 수 있습니다. 적용 직전에 파일과 연결 정보를 다시 확인합니다. 파일 이동이나 DB 갱신이 실패하면 해당 영상과 자막의 이름을 되돌립니다. 외부 프로그램이 같은 경로에 새 파일을 만들어 복구까지 막힌 경우에는 덮어쓰지 않고 보존된 파일의 현재 경로를 오류 결과로 안내합니다.

이름 변경은 대상 경로를 덮어쓰지 않는 하드 링크 생성 후 원래 이름을 제거하는 방식입니다. NTFS처럼 하드 링크를 지원하는 파일시스템과 해당 권한이 필요합니다. 지원하지 않는 파일시스템에서는 원본을 보존하고 오류로 안내하며 다른 이동 방식으로 자동 전환하지 않습니다. 링크 생성 후 원래 이름 제거에 실패하면 두 경로를 보존하고 확인할 경로를 표시합니다.

**작업 취소**는 아직 시작하지 않은 항목을 중단합니다. 이미 완료한 영상 묶음은 유지하고, 결과에서 완료·실패·변경 안 함 개수를 확인할 수 있습니다. 파일 자체의 내용은 바꾸지 않습니다.

## 정확한 중복 후보

**정확한 중복 후보 찾기**는 실제 크기가 같은 원본 파일의 처음부터 끝까지 읽어 SHA-256을 비교합니다. 기존 가져오기용 부분 해시를 재사용하지 않습니다. 검사 중 파일이 바뀌거나 읽을 수 없거나 앱 작업에 사용 중이면 제외 이유를 표시합니다. 대용량 영상은 시간이 걸리며 검사 도중 취소할 수 있습니다.

이 기능은 바이트 내용이 같은 파일의 후보를 찾습니다. 화면이 비슷한 영상이나 재인코딩·화질 변경·편집된 영상의 유사도를 판정하지 않습니다. 결과는 검사 시점의 상태이며, 하드 링크로 같은 저장 공간을 공유하는 경로가 포함될 수도 있습니다.

파일은 자동 삭제하지 않습니다. 후보의 **라이브러리에서 확인**으로 영상을 선택한 뒤 실제 경로와 내용을 확인하고, 필요한 경우 기존의 안전한 삭제 기능을 사용합니다. 모든 처리는 로컬에서 이루어지며 파일 내용이나 해시를 외부로 전송하지 않습니다.
