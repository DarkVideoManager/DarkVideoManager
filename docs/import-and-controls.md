# 영상 추가와 재생 조작

라이브러리를 열면 상단에 **영상 파일 추가**, **폴더 가져오기**, **목록 업데이트**가 표시됩니다.

| 목적                             | 사용할 버튼                                   | 처리 범위                                                                                                    |
| -------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 영상 한 개 또는 고른 파일만 추가 | 영상 파일 추가 → 파일 선택 → 선택한 영상 추가 | 선택한 파일의 정보·썸네일과 같은 폴더의 대응 자막만 처리합니다. 다른 영상이나 하위 폴더를 검색하지 않습니다. |
| 폴더를 처음 등록                 | 폴더 가져오기 → 선택 → 가져오기               | 폴더와 하위 폴더의 영상을 추가하고 해당 폴더를 갱신 대상으로 등록합니다.                                     |
| 등록 폴더에 생긴 새 영상 반영    | 목록 업데이트                                 | 등록 폴더를 검색하여 새 영상을 추가하고 사라진 영상을 제거한 항목으로 옮깁니다.                              |

폴더 자동 감시는 지원하지 않습니다. 폴더 내용이 바뀌면 **목록 업데이트**를 눌러 수동 반영하세요. 파일 추가로만 가져온 영상의 폴더는 갱신 대상으로 등록되지 않으며, 해당 폴더의 새 영상까지 반영하려면 폴더 가져오기를 이용합니다. 원본 파일은 복사하지 않고 선택한 위치를 연결합니다.

이미 등록된 경로의 영상은 정보와 썸네일을 다시 만들지 않습니다. 같은 경로의 파일을 덮어썼을 때도 자동으로 재분석하지 않습니다. 대응 자막 목록은 갱신하며, 썸네일이 없는 영상은 생성을 다시 시도합니다. 별점·메모·하이라이트와 사용자가 목록에서 제거한 상태는 유지합니다. 폴더에 접근할 수 없는 경우에는 누락된 영상으로 일괄 처리하지 않습니다.

작업 중에는 파일 검색·영상 분석·썸네일 단계와 진행 수를 확인하고 **작업 취소**로 중단할 수 있습니다. 처리한 항목은 보존합니다. 끝난 뒤 추가·기존·제거·오류 수와 실패 내용을 확인하세요.

## 조작 안내 열기

라이브러리 상단의 **조작 안내**, **설정 → 단축키·재생 조작 안내**, 재생 화면 왼쪽 위의 **조작 안내**에서 현재 지원하는 키와 조작 방법을 확인할 수 있습니다. 안내는 스크롤할 수 있으며 `Esc`로 닫으면 열었던 버튼으로 돌아갑니다.

왼손 조작은 별도 모드 전환 없이 지원합니다. `A`/`D` 또는 `←`/`→`로 앞뒤로 이동하고, `Q`/`E`로 이전·다음 하이라이트, `Z`/`C`로 이전·다음 자막으로 이동합니다. 기본 이동은 1초이며 **설정 → 재생 탐색 → 기본 탐색 간격 (초)**에서 1–600초의 정수로 바꾸고 저장할 수 있습니다. `Shift`를 함께 누르면 5초, `Ctrl`을 누르면 30초이며 이 간격은 바뀌지 않습니다. 이동 키를 길게 누르면 연속 이동하며 점차 빨라집니다.

숫자 `0`–`9`는 영상의 0–90% 위치로 이동합니다. 숫자패드는 NumLock을 켜고 사용합니다. 재생·일시정지 상태를 유지하며, 영상 길이를 알 수 없거나 `Shift`·`Ctrl`·`Alt`와 함께 누른 숫자는 구간 이동에 사용하지 않습니다. 입력란이나 대화상자를 사용하는 동안 재생 단축키는 실행되지 않습니다.

음량은 `↑`/`↓`로 5%씩 조절하고 다음 영상에도 유지합니다. **전체화면** 또는 `Alt+Enter`로 전체화면을 전환하고 `Esc`로 해제합니다. 일반 재생 화면에서 `Esc`는 라이브러리로 돌아갑니다. **플레이어 최대화**는 상세 패널을 숨기고, **상세 보기**는 패널을 다시 표시합니다. 앱 창은 제목 표시줄의 최대화 버튼이나 창 가장자리로 크기를 조절합니다.

`+`/`-` 버튼·키로 100–400% 확대·축소하며, 확대된 영상을 드래그하여 위치를 옮길 수 있습니다. **화면 맞춤**은 배율과 위치를 초기화합니다. **재생 정보** 또는 `I`로 영상 정보를 표시·숨기며, `Tab`은 버튼 사이의 초점 이동을 유지합니다. 전체화면·확대는 인앱 재생에서 지원합니다. `F`/`T`는 현재 화면을 대표 썸네일로 지정하는 키이며 자유로운 키 재지정 설정은 제공하지 않습니다.

**설정 → 외부 플레이어**에서 mpv, ffplay 또는 VLC를 선택할 수 있습니다. 앱에서 여는 mpv는 다음 실행부터 저장한 기본 탐색 간격을 사용하며, 숫자 구간 이동과 `F` 키 썸네일 지정을 지원합니다. VLC·ffplay의 이동 간격과 외부 플레이어의 전체화면·확대는 해당 플레이어 설정을 따릅니다.
