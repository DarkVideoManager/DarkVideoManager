# 구간 반복·영상 정보·라이브러리 선택

## A-B 구간 반복

인앱 플레이어에서 원하는 위치로 이동하여 **A 시작점 설정**, 구간 끝으로 이동하여 **B 끝점 설정**, **반복 켜기**를 누릅니다. B는 A보다 최소 0.1초 뒤여야 하며 두 위치 모두 영상 길이 안에 있어야 합니다. 기존 **재생 배속**의 0.25–4배와 함께 사용할 수 있습니다.

반복 중 재생 위치가 범위를 벗어나면 A로 돌아갑니다. 일시정지한 상태에서는 범위 밖으로 탐색해 위치를 확인할 수 있고 다시 재생하면 A-B 범위로 돌아갑니다. **반복 끄기**로 일반 재생을 계속하거나 **구간 초기화**로 A/B를 지웁니다. 영상·라이브러리·재생 소스를 바꾸거나 플레이어를 닫으면 구간이 초기화됩니다.

앱의 A-B 조작은 인앱 플레이어에서 지원합니다. mpv·VLC·FFplay를 외부 창으로 실행했다면 해당 플레이어의 반복 조작을 사용합니다. 코덱·디코더·탐색 가능 위치에 따라 경계에서 시간 차이가 있을 수 있으며 프레임 단위 편집 기능은 아닙니다.

## 재생 전 영상 정보와 상세 탭

영상을 한 번 선택하면 **정보** 탭에서 수집된 프레임레이트(FPS), 해상도, 길이, 코덱, 컨테이너, 비트레이트(kbps), 파일 크기와 위치를 확인합니다. 재생이나 AI 도구 설치가 필요하지 않습니다. 분석하지 못한 값은 **정보 없음**으로 표시합니다. FPS는 수집한 평균 프레임레이트로, 가변 프레임레이트 영상의 매 순간 FPS를 보증하지 않습니다.

**하이라이트**에서는 저장한 장면을 확인하고, **자막 생성**에서 모델·언어를 선택해 생성합니다. 정보 탭만 열면 AI 환경을 조회하거나 자막 생성을 시작하지 않습니다. 생성 탭의 모델·언어는 다른 상세 탭을 오갈 때 유지되며, 실행한 작업은 대기열에서 계속 진행됩니다. 제출하지 않은 기존 자막 삭제 확인은 탭을 바꾸면 취소됩니다. 플레이어의 **자막 탐색** 탭도 유지합니다.

## 여러 폴더·드라이브로 라이브러리 만들기

상단 **라이브러리 관리**에서 새 라이브러리를 만들 때 선택 창에서 여러 폴더를 선택할 수 있습니다. 저장매체 전체를 대상으로 하려면 드라이브 루트를 선택합니다. 등록한 모든 폴더는 **목록 업데이트**의 대상이 됩니다. 기존 라이브러리의 **폴더 가져오기**에서도 여러 폴더를 한 번에 추가합니다.

중복 선택과 선택한 상위 폴더에 포함된 하위 폴더는 중복 등록하지 않습니다. 모든 경로를 확인하고 검색을 완료한 뒤 가져오기를 적용합니다. 접근 실패를 빈 목록처럼 적용하여 기존 영상을 제거하지 않습니다. Windows 드라이브 루트 바로 아래의 휴지통·시스템 볼륨 메타데이터 폴더는 제외합니다. 다른 보호 폴더나 연결이 끊긴 저장매체는 오류가 표시될 수 있습니다.

## 앱을 종료하지 않고 라이브러리 전환

상단 **라이브러리 전환**에서 저장된 라이브러리를 선택합니다. 새 데이터베이스를 성공적으로 연 뒤 화면을 바꾸며 선택 영상은 해제하고 검색·정렬·필터는 라이브러리별 설정을 사용합니다. 실패하면 기존 화면을 유지합니다. 앱이 관리하는 이전 외부 플레이어와 재생 세션은 종료합니다.

기존 데이터베이스는 진행 중인 자막·썸네일 작업을 위해 유지되며 작업은 원래 라이브러리에 귀속됩니다. 진행 중인 가져오기·갱신은 원래 라이브러리로 돌아와 확인·취소합니다. 해당 작업이 완료되기 전에는 새 라이브러리의 가져오기·갱신을 잠시 사용할 수 없습니다. 저장 목록의 추가·삭제는 **라이브러리 관리**에서 합니다.
