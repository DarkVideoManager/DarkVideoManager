# 개인정보와 네트워크 사용

이 문서는 현재 소스의 저장·통신 동작을 설명합니다. DarkVideoManager는 로컬 영상 관리 앱이며, 계정 가입이나 운영자 서버로의 영상 업로드 기능은 없습니다. 현재 앱 코드에는 사용 분석 이벤트나 자동 오류 보고를 운영자에게 전송하는 기능이 없습니다. 선택한 번역·Stash 메타데이터 조회 기능, 긴급 탈출의 지정 웹페이지 열기, 설치·모델 다운로드에는 네트워크가 사용됩니다.

앱 **설정** 또는 자막 생성·환경 설치·한국어 번역 설정에서 **개인정보 처리 · 공식 배포 확인**을 펼치면 전송 조건의 요약, 이 문서, 공식 다운로드 링크를 확인할 수 있습니다. 링크를 직접 열면 기본 브라우저에서 GitHub에 접속합니다.

## 공식 배포 파일 확인

실행파일은 [공식 GitHub Releases](https://github.com/DarkVideoManager/DarkVideoManager/releases)에서 받습니다. 선택한 릴리스에 제공된 `SHA256SUMS.txt`와 `VERIFICATION.md`를 확인하고, 내려받은 실행파일의 SHA-256을 같은 릴리스의 값과 비교하세요. 소스 압축 파일과 Windows 실행파일은 용도가 다릅니다. 배포 산출물의 구성은 [릴리스 안내](release.md)에 있습니다.

해시 일치는 내려받은 파일이 해당 배포 파일과 같은지 확인하는 절차입니다. 공개 소스, 해시 일치, 백신 검사 결과 어느 하나만으로 독립적인 보안 감사를 받았거나 안전이 보증된다고 표현하지 않습니다. 게시자·릴리스·파일이 예상과 다르거나 경고 원인을 판단할 수 없으면 실행을 보류하고 공식 이슈 또는 [보안 제보 경로](../SECURITY.md)로 확인하세요. 보안 경고를 해제하거나 백신 예외를 추가하는 것을 설치 절차로 안내하지 않습니다.

## PC에 저장하는 내용

기본 앱 데이터 폴더는 `%APPDATA%\dark-video-manager`입니다. 개발·테스트 실행에서 별도 데이터 경로를 지정하면 위치가 달라질 수 있습니다.

| 위치                                                      | 내용                                                                                                                |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `config.json`과 백업                                      | 라이브러리 이름·영상 폴더 경로·앱 설정·라이브러리별 즐겨찾기와 선호 태그·화면 보호 설정과 탈출 웹 주소              |
| `libs/*.db`                                               | 영상 경로·메타데이터·태그·평점·하이라이트·재생 기록·자막 등록 정보                                                  |
| `thumbnails/`                                             | 영상에서 추출하거나 사용자가 지정한 이미지                                                                          |
| `playback-proxies/`                                       | 호환 재생을 위해 변환한 영상과 원본 확인 정보                                                                       |
| `subtitle-queue.json`, `subtitle-jobs/`                   | 자막 대기열, 추출한 음성, 중간 자막·번역 결과와 재개 정보                                                           |
| `subtitle-environment.json`                               | 앱 전용 Linux 계정을 사용하는 WSL 배포판 목록                                                                       |
| `subtitle-wsl-install.json`, `subtitle-wsl-install-*.ps1` | Windows 설치 단계·프로세스 ID와 시작 시각, 설치 도우미. 중복 설치 방지와 재시도에 사용하며 완료 확인 후 정리합니다. |
| `cloud-translation.json`                                  | 번역 사용 설정·월별 문자 수·암호화된 API 키                                                                         |
| `stash-metadata.json`                                     | Stash 사용 설정·사용자가 지정한 서버 주소·암호화된 API 키                                                           |

생성한 SRT 자막은 원본 영상과 같은 폴더에 저장합니다. 썸네일과 재생 캐시, 추출 음성, DB, 일반 설정, 자막 텍스트는 앱에서 암호화하지 않습니다. API 키는 Electron `safeStorage`를 통해 Windows 보안 저장소를 사용해 암호화하며, 암호화를 사용할 수 없으면 키 저장을 거부합니다. 같은 Windows 계정으로 실행되는 다른 프로그램이나 관리자 접근까지 차단하는 보관함은 아닙니다.

실행 로그·오류 메시지에는 파일 경로와 처리 상태가 포함될 수 있습니다. 앱 데이터, 콘솔 출력, 스크린샷을 공유하기 전에 개인 파일명과 폴더 경로를 확인하세요. 앱 설치 폴더나 데이터 폴더를 OneDrive 등 동기화 폴더에 두면 해당 서비스의 설정에 따라 파일이 동기화될 수 있습니다.

## 기능별 통신

| 기능                                   | 처리 위치와 전송 내용                                                                                                                                                                                                                                                                                                               |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 라이브러리 검색·재생·하이라이트·썸네일 | PC에서 처리합니다. 앱이 운영자에게 영상이나 기록을 보내지 않습니다.                                                                                                                                                                                                                                                                 |
| AI 음성 인식                           | 새 작업은 Windows의 whisper.cpp/Vulkan으로 처리합니다. 기존 CPU 작업은 WSL에서 재개할 수 있습니다. 인식용 영상·음성을 클라우드 API에 보내지 않습니다.                                                                                                                                                                               |
| 모델·개발 환경 준비                    | 모델이 없으면 Hugging Face에서 다운로드합니다. **자막 환경 자동 설치**를 실행하면 Microsoft·Ubuntu 배포처, Python 패키지 배포처, GitHub의 Ollama 공식 배포 파일과 Ollama 모델 저장소에서 필요한 구성 요소를 받습니다. 개발용 설치 스크립트는 npm·Python 배포처 등도 사용합니다. 영상·자막 내용을 다운로드 요청에 첨부하지 않습니다. |
| 로컬 한국어 번역                       | WSL 안의 `http://127.0.0.1:11434`에서 실행 중인 Ollama로 자막 문장과 번역 지시를 전달합니다. 기본 모델은 `qwen3:8b`이며 **자막 환경 자동 설치**에서 준비할 수 있습니다. 일반 자막 생성 중에는 번역 모델을 내려받지 않습니다.                                                                                                        |
| Google Cloud 한국어 번역               | 사용자가 API 키를 저장하고 **Google Cloud Translation 사용**을 켠 경우, 한국어 번역 작업에서 자막 문장·원문 언어·번역 설정과 API 인증 정보를 `translation.googleapis.com`에 HTTPS로 보냅니다. 원본 영상·음성·파일 경로는 이 API 요청에 포함하지 않습니다.                                                                           |
| Stash 메타데이터 조회                  | 기본으로 꺼져 있습니다. **Stash 연결 사용**을 켜고 **Stash에서 후보 조회**를 눌렀을 때만, 입력한 파일명 또는 식별자와 API 인증 정보를 지정한 Stash 서버의 `/graphql`에 보냅니다. 원본 영상·표지·재생 기록이나 검색어에 입력하지 않은 파일 경로는 전송하지 않습니다.                                                                 |
| 추천 탐색·중복 후보 확인               | PC의 등록 영상·태그·즐겨찾기·시청 기록을 이용하며 외부 서비스에 검색어나 이력을 보내지 않습니다. 중복 확인은 원본 파일 전체를 로컬에서 읽어 SHA-256을 비교합니다.                                                                                                                                                                   |
| 긴급 탈출의 지정 웹페이지 열기         | 사용자가 이 동작과 HTTPS 주소를 저장한 뒤 긴급 탈출을 실행할 때 기본 브라우저로 해당 주소를 엽니다. 설정 저장만으로 접속하지 않습니다. 일반 웹 방문과 같은 접속 정보·브라우저 기록이 남을 수 있습니다.                                                                                                                              |

Stash 연결은 HTTPS 또는 `localhost`·`127.0.0.1`·`[::1]`의 HTTP만 허용하며 리다이렉트를 따르지 않습니다. 조회는 15초와 응답 1 MiB로 제한합니다. 서버 주소를 변경하면 이전 서버의 저장된 API 키를 제거합니다. 설정 저장과 화면 열기에는 서버 통신이 없으며 자동 조회·웹사이트 수집·Stash 데이터 수정·표지 다운로드는 하지 않습니다. 검색어에는 개인 파일명 등이 포함될 수 있고 서버 측 로그·보관 정책은 사용자가 지정한 서버의 설정에 따릅니다. 결과는 검토 후 선택한 제목·메모·태그만 로컬 DB에 저장합니다. [사용 방법과 지원 범위](METADATA_IMPORT.md)를 참고하세요.

Google Cloud 사용은 기본으로 꺼져 있습니다. **한국어 번역** 선택과 **Google Cloud Translation 사용** 설정은 별개입니다. 키가 없거나 사용을 끄거나 앱의 남은 문자 한도가 부족하거나 요청에 실패하면 로컬 Ollama로 전환합니다. 한 작업에서 로컬로 전환한 뒤 남은 자막도 로컬에서 처리합니다. 로컬 모델·서버가 준비되지 않았다면 번역 실패를 표시하며 원어 자막을 유지합니다.

Windows의 음성 모델 다운로드는 앱에 포함된 Mozilla 공개 인증서 묶음(certifi 제공)을 기존 시스템 인증서와 함께 사용합니다. 앱은 묶음의 SHA-256을 확인하고 다운로드 프로세스 안에서만 사용하며, Windows 인증서 저장소에 인증서를 추가하거나 서버 인증서 검사를 끄지 않습니다. 인증서 파일에는 사용자 정보가 포함되지 않습니다.

자동 설치는 기존에 실행 중인 로컬 Ollama 서버를 우선 사용합니다. 앱이 새로 설치한 Ollama는 WSL의 `~/.local/share/dark-video-manager/ollama/`, 모델은 `ollama-models/`, 실행 로그는 `ollama.log`에 저장합니다. 앱이 시작하는 서버는 WSL의 로컬 주소에만 연결을 받으며 앱 전용 설치본에는 클라우드 기능을 끕니다. 준비가 끝난 번역 서버는 앱 종료 후에도 WSL에서 실행 중일 수 있고, 다음 번역 작업에서 필요하면 다시 시작합니다.

Ubuntu는 앱을 실행한 Windows 사용자 계정에 설치하며, 관리자 권한은 Windows의 WSL 구성 요소 준비에 사용합니다. Ubuntu 기본 사용자가 아직 `root`이면 암호 로그인이 잠긴 Linux 계정 `dvm-subtitles`를 만들고, `/var/lib/dark-video-manager/user`를 홈으로 사용합니다. 이 경우 위 `~` 경로도 해당 홈을 기준으로 합니다. 기존의 일반 Ubuntu 사용자 계정은 변경하지 않습니다. 전용 계정 연결 정보는 앱 데이터의 `subtitle-environment.json`, 계정 생성 확인 정보는 WSL의 `/var/lib/dark-video-manager/subtitle-user`에 저장합니다.

Google에 보낸 텍스트에는 영상 속 대화나 개인정보가 들어 있을 수 있습니다. 활성화 전에 전송할 수 있는 자료인지 확인하세요. Google 측 처리 조건은 [Cloud Translation 데이터 사용 안내](https://docs.cloud.google.com/translate/data-usage)를 따릅니다. 앱이 사용하는 Basic의 글로벌 엔드포인트에는 특정 국가·지역 내 처리 설정이 없습니다. 사용자가 따로 설치한 Ollama·외부 플레이어·운영체제·동기화 프로그램의 통신은 각각의 설정에 따릅니다.

## 설정과 삭제

즐겨찾기와 선호 태그는 **추천 탐색**에서 해제·비우기 할 수 있습니다. 이 설정을 지워도 기존 영상의 별점·재생 기록은 유지됩니다. 화면 보호는 **설정 → 화면 보호**에서 변경합니다. 썸네일 가림과 긴급 탈출은 화면 표시와 재생 종료 기능이며 원본·캐시·브라우저 방문 기록을 지우거나 데이터를 암호화하지 않습니다. [추천 탐색과 화면 보호 안내](library-discovery-and-privacy.md)에서 적용 범위를 확인하세요.

Stash 조회를 중지하려면 영상 상세 정보의 **Stash에서 정보 가져오기 → Stash 연결 사용**을 끄고 **연결 설정 저장**을 누릅니다. 저장 시 진행 중인 조회도 취소하지만 이미 서버에 전달된 검색어를 회수할 수는 없습니다. **저장된 Stash API 키 삭제**를 선택하고 저장하면 앱의 키를 제거하며 서버의 키 폐기는 Stash에서 별도로 해야 합니다. 서버 주소와 사용 설정은 `stash-metadata.json`에 남고 이미 적용한 메타데이터는 라이브러리에 남습니다.

온라인 번역을 중지하려면 **자막 생성 → 한국어 번역 설정**에서 Google Cloud 사용을 끄고 저장합니다. 진행 중인 요청을 멈추려면 해당 자막 작업을 일시정지하거나 삭제하세요. 이미 전송된 요청을 취소해도 Google에 도착한 텍스트를 회수할 수는 없습니다. **저장된 API 키 삭제**는 앱이 보관한 키를 제거하며, Google에서 키를 폐기하는 작업은 Google Cloud 콘솔에서 별도로 해야 합니다.

자막 큐 항목을 삭제하면 미완성 중간 파일을 정리하고 이미 저장한 SRT는 유지합니다. 실패·일시정지한 작업의 중간 결과는 재개를 위해 남습니다. 재생 캐시 정리는 `playback-proxies`의 변환 자료를 대상으로 하며 원본 영상이나 자막을 지우지 않습니다. 앱의 데이터 삭제 화면에서 표시하는 대상과 원본 삭제 여부를 확인하세요.

PC에서 앱 데이터를 직접 정리할 때는 트레이까지 완전히 종료하고 필요한 자료를 백업한 뒤 위 앱 데이터 폴더를 확인합니다. 원본 영상 옆의 SRT, `%LOCALAPPDATA%\DarkVideoManager\subtitles`의 다운로드·모델, WSL의 전용 Python 환경·모델 캐시, Ollama 모델은 별도 위치에 남을 수 있습니다. 프로그램 제거만으로 이 자료가 모두 삭제된다고 가정하지 마세요.

`subtitle-environment.json` 삭제는 Linux 계정이나 모델을 삭제하지 않습니다. 이 파일을 보관하면 Ubuntu의 기본 사용자가 바뀌어도 전용 환경을 계속 찾을 수 있습니다. Ubuntu 배포판 자체를 초기화·삭제하면 그 안의 모델과 도구도 없어지므로 다시 설치해야 합니다.

Windows 설치 도우미는 앱을 종료해도 진행 중인 설치를 강제로 중단하지 않습니다. `subtitle-wsl-install.json`에는 완료 여부와 프로세스 시작 시각을 남겨, 다시 자동 설치를 눌렀을 때 같은 작업을 확인합니다. Ubuntu 설치의 임시 출력 파일(`subtitle-wsl-install.json.*.out`, `*.err`)은 정상 완료 시 정리합니다. 설치가 진행 중일 때는 이 기록과 도우미 파일을 직접 지우지 마세요.

공개 이슈에는 실제 API 키·DB·개인 영상·전체 로그를 첨부하지 마세요. 보안 문제의 제보 경로는 [SECURITY.md](../SECURITY.md)에 있습니다.
