# DarkVideoManager 소개 웹사이트

한국어 반응형 소개 페이지와 실제 앱의 React 화면을 재사용하는 브라우저 체험판입니다. 공개 사용이 가능한 야구 샘플 영상을 포함하며, 개인 데이터나 Windows 설치 파일은 포함하지 않습니다.

공개 주소: https://dark-video-manager.vercel.app/

## 0.3.0 안내 기준

홈페이지의 기능·지원 안내는 [Windows 앱 0.3.0](https://github.com/DarkVideoManager/DarkVideoManager/releases/tag/v0.3.0)을 기준으로 합니다. 카테고리·태그 분류, 개별 파일 가져오기, 파일명 변경 미리보기와 동일 파일 찾기, 재생 이동 간격·숫자 키 탐색·확대·재생 정보, 자막 작업의 처리 장치 표시, 선택적인 Stash 정보 가져오기를 소개합니다. 다운로드 버튼과 집계는 특정 버전에 고정하지 않고 최신 정식 릴리스를 자동 조회합니다.

Stash는 사용자가 서버를 설정하고 사용을 켠 뒤 직접 조회할 때만 통신합니다. 조회 결과를 확인·수정한 뒤 제목·메모·태그 중 선택한 필드만 적용하며, 인물은 선택적으로 태그에 추가합니다. 임의 사이트 자동 수집이나 영상 업로드 기능으로 소개하지 않습니다. 새 음성 인식 작업은 Vulkan GPU를 사용하며 GPU 사용 실패 시 CPU로 자동 전환하지 않습니다. 로컬 번역과 Google 번역의 대체 동작은 음성 인식의 CPU 전환과 구분합니다.

현재 배포 대상은 Windows 10/11 x64의 로컬 영상입니다. 다른 운영체제·ARM·모바일·스트리밍·전용 NAS 연동 및 VSR·SVP는 구현 또는 검증된 기능으로 안내하지 않습니다. 지원 범위는 [플랫폼·재생 안내](../docs/platform-and-playback-scope.md)를 따릅니다.

0.3.0의 [공개 검증 기록](https://github.com/DarkVideoManager/DarkVideoManager/releases/download/v0.3.0/VERIFICATION.md)은 공식 단위 검사 594개, 브라우저 동작 검사 164개, Windows 호스트에서의 포터블 시작·종료와 패키지 구성 확인, Radeon RX 9060 XT의 Vulkan GPU·base 모델을 사용한 짧은 영어 합성 음성의 원어 자막 생성을 구분해 기록합니다. 새 Windows 환경의 설치형 설치·제거, WSL 설치·재시작, 모든 GPU·언어·모델 및 한국어 번역 품질을 이번 버전에서 검증했다고 쓰지 않습니다. 실행 파일은 미서명이며, V3 차단 제보는 재현 자료가 부족해 해소를 확인하지 못했습니다. 다운로드·해시 확인과 제보 방법은 [다운로드 검증 안내](../docs/download-verification.md)로 연결합니다.

## 로컬 실행

저장소 루트의 의존성을 설치한 상태에서 이 폴더의 `npm run build:demo`로 실제 앱 화면을 `public/demo`에 빌드합니다. `npm run dev` 실행 후 http://127.0.0.1:4178 을 엽니다. 체험판만 보려면 `/demo/`를 엽니다.

`demo/main.tsx`는 실제 `src/renderer/App`과 스타일을 불러옵니다. `demo/api.ts`는 Electron 통신 대신 브라우저 저장소와 영상 캡처, 자막 생성 시뮬레이션을 제공합니다. 자막 생성은 약 15초의 진행 과정과 일시정지·재개·취소·재생성, 예시 VTT 저장을 체험하는 기능이며 실제 AI 추론을 하지 않습니다. 자막은 수작업 장면 설명이고 모델 선택에 따른 품질 차이는 없습니다. 실제 설치·클라우드 키 설정 UI는 브라우저 전용 체험 카드로 대체합니다. `demo/browser-copy.ts`의 빌드 시 문구 변환은 실제 앱 코드나 Windows 빌드를 수정하지 않습니다.

데모는 Windows 앱 전체 기능의 실행 환경이 아닙니다. 로컬 파일 관리, 외부 플레이어 제어, Stash 조회, Google 번역, 도구 설치와 실제 GPU 자막 생성이 동작하는 것으로 안내하지 않습니다. 앱의 설정·기능이 추가되면 브라우저 API 어댑터에서 지원하는 범위와 예시 화면을 함께 확인한 뒤 배포합니다.

초기 통계·별점·메모·하이라이트·완료된 자막 작업은 예시 데이터임을 화면에 표시합니다. 이후 조작과 결과는 브라우저에 저장되며 새로고침 시 미완료 작업은 일시정지 상태로 복원합니다. 기존 저장 데이터는 사용자 변경사항을 보존하며 마이그레이션합니다. 저장소가 막히거나 가득 찬 경우 완료로 가장하지 않고 오류를 표시합니다.

브라우저 플레이어는 W로 재생·일시정지, A/D로 1초 탐색(Shift는 5초), S로 현재 장면의 하이라이트와 캡처를 저장합니다. A/D/S는 실제 앱의 동작을 재사용하며 W는 브라우저 체험용 별칭입니다. 화면의 WASD 버튼은 터치로도 누를 수 있습니다. 한글 키보드의 물리 키 위치를 지원하며 입력창·편집 영역·대화상자에서는 조작하지 않고 Ctrl/Alt/Command 조합은 브라우저에 맡깁니다.

Q/E는 이전·다음 하이라이트, Z/C는 선택한 자막의 이전·다음 구간으로 이동합니다. 실제 앱의 탐색 동작을 재사용하며 자막 항목을 선택한 뒤에도 사용할 수 있습니다. 화면 키 안내에 클릭 가능한 버튼과 눌림 표시를 제공하고, 이동할 항목이 없으면 기존 플레이어의 안내를 표시합니다.

## 배포

먼저 `npm run build:demo`를 실행하고 Vercel에 **website 폴더만** 배포합니다. `public`은 정적 파일이며, `api/releases.js`와 `lib/releases.js`는 다운로드 정보를 읽는 Vercel Node.js 함수입니다. 배포에는 `package.json`, `vercel.json`도 포함합니다. 저장소 전체나 Electron 빌드/검증 폴더는 업로드하지 않습니다. `.env*`는 배포 및 Git에서 제외합니다.

소스 저장소: https://github.com/DarkVideoManager/DarkVideoManager

Windows 설치 파일과 포터블 파일은 [최신 정식 릴리스](https://github.com/DarkVideoManager/DarkVideoManager/releases/latest)에서 배포합니다. 소개 페이지는 `/api/releases`를 통해 최신 버전의 설치형·포터블 링크와 각각의 다운로드 횟수를 자동으로 표시합니다. 누적 횟수는 모든 공개 정식 릴리스에 첨부된 `DarkVideoManager-Setup-{version}-x64.exe`와 `DarkVideoManager-Portable-{version}-x64.exe`만 합산합니다. 미리 보기 릴리스와 소스·문서 다운로드는 제외합니다.

GitHub의 `download_count`는 사용자 수나 설치 완료 수가 아닙니다. 반복 다운로드와 배포 검증 요청이 포함될 수 있습니다. 서버와 CDN은 정상 응답을 10분 캐시하며, 화면은 열려 있는 동안 10분 간격으로 다시 조회합니다. CDN은 갱신 중 만료된 응답을 최대 1시간 더 제공할 수 있으며, 화면에 실제 집계 시각을 표시합니다. 조회 실패 시 기존 수치를 0으로 바꾸지 않으며, JavaScript를 사용할 수 없거나 최초 조회가 실패해도 GitHub 최신 릴리스 링크를 제공합니다. API 토큰, 방문자 추적 또는 추가 데이터베이스는 사용하지 않습니다.

상단 **Windows 다운로드**는 첫 화면의 다운로드 영역으로 바로 이동합니다. 설치형은 `Setup .exe`를 실행해 설치 안내를 따르고 시작 메뉴에서 실행합니다. 포터블은 `Portable .exe`를 받아 설치 마법사 없이 실행하지만 설정·캐시는 PC에 저장됩니다. 둘 중 하나만 받으면 됩니다. GitHub의 **Assets**에서 이 실행 파일을 선택하며 **Source code (zip / tar.gz)**는 개발용 코드라 앱으로 실행할 수 없습니다. 브라우저 데모는 별도 샘플 체험이며 실제 AI 추론·내 영상 관리에는 Windows 앱이 필요합니다. 다운로드 영역에서 [파일 검증 안내](../docs/download-verification.md)로 바로 이동할 수 있습니다.

`npm run test:e2e -- --workers=1`은 데스크톱·모바일 화면의 다운로드 이동, 공식 자산 링크, 설치형·포터블 설명, 소스 구분, 검증 링크, API 실패 및 JavaScript 비활성화 시 경로를 확인합니다. 테스트는 릴리스 API 응답을 격리하며 실행 파일을 다운로드하거나 실행하지 않습니다.

생성된 `public/demo` 번들은 Git에 포함하지 않으므로 배포 전 `npm run build:demo`를 실행하세요. 배포 전 `npm run check`와 `npm test`로 사이트 스크립트와 릴리스 조회 동작을 확인합니다. 앱 설치·자막·GPU 검증 결과는 해당 버전의 공개 검증 기록과 일치해야 하며, 이전 버전이나 다른 환경의 결과를 현재 버전의 결과로 옮겨 쓰지 않습니다.

웹사이트는 외부 글꼴, 분석 도구, 쿠키, 외부 이미지 요청을 사용하지 않습니다. 영상과 썸네일도 직접 호스팅합니다. D. Benjamin Miller의 CC0 영상과 NARA가 제공하는 퍼블릭 도메인 기록 영상을 사용합니다. 개별 출처와 변환 기록은 `public/media-credits.html` 및 `public/demo-media/media-manifest.json`에 있습니다. 원본 아이콘은 프로젝트의 권한 확인된 아이콘입니다. Windows 앱의 통신 안내는 [개인정보 안내](../docs/PRIVACY.md), 설치 요구사항은 [자막 안내](../docs/subtitles.md), Stash의 명시적 조회·선택 적용은 [정보 가져오기 안내](../docs/METADATA_IMPORT.md)를 기준으로 작성했습니다. 도구·모델 다운로드와 Google 번역 외에 Stash 조회 및 사용자가 선택한 외부 웹페이지 열기도 구분해 안내합니다.
