01 / 주요 기능

영상 관리·재생·자막

Windows 앱에서 사용할 수 있는 주요 기능입니다.

라이브러리 주요 기능

기본적으로 파일 탐색기가 제공하는 기능은 대부분 제공합니다.

  • 영상마다 몇 번 봤는지, 얼마나 오래 봤는지 기록하고 보여줍니다.
  • 영상에 대한 나의 평점을 매겨 나중에 평점별로 정렬해서 볼 수도 있습니다.
  • 자막이 있는 영상인지 없는 영상인지 화면에 표시하고, 자막이 없으면 바로 생성 가능합니다.
  • 내가 많이 본 순서로 정렬하거나, 안본 순서로 정렬할 수도 있습니다.
  • 도저히 못보겠는 영상은 삭제할수도 있습니다.

동영상 플레이어 기본 기능

기본적으로 동영상 플레이어가 제공하는 기능은 대부분 제공합니다.

  • 가속도 센서가 달린 재생 이동기능 A·D로 1초씩 이동합니다. 길게 누를수록 더 빨라져 불필요한 장면을 빠르게 넘길 수 있습니다.
  • 하이라이트 기능 중요한 장면, 스토리상 분기점, 특정 동작을 시작하는 장면 등으로 빠르게 이동할 수 있도록 S를 누르면 언제든지 해당 순간을 저장하고 나중에 하이라이트 탭이나 단축키 Q·E로 다시 이동할 수 있습니다.
  • 자막 이동 보통 자막이 있는 부분은 불필요하므로 빠르게 자막만 보면서 넘길 수 있습니다. Z·C로 이전·다음 자막으로 이동합니다. 한번에 자막을 훑어볼 수 있게 자막 탐색기도 제공합니다.

통계 기능

내가 이 프로그램에 얼마나 시간을 썼는지, 뭘 가장 많이 봤는지, 주요 사용 태그 등 다양한 데이터를 보여줍니다.

긴급 탈출 기능

모든 상황에서 ESC를 누르면 즉시 이전 화면으로 돌아갑니다. (ESC를 따닥 누르면 바로 꺼짐) 라이브러리와 자막 작업 화면에서는 창을 닫습니다. 자막 생성중이라면 프로그램은 백그라운드에 그대로 둡니다.

자막 작업이 남아 있으면 창을 닫아도 백그라운드에서 계속 진행합니다.

자막 생성 기능

영상 속 말소리를 AI가 자막으로 만듭니다. 한국어 번역은 내 PC에서 처리하거나, Google Cloud API 키를 등록하고 사용을 켜서 이용할 수 있습니다.

설정 방법이 어렵다면 GPT나 클로드한테 자막 생성과 번역 설정 방법을 물어보시면 될 것 같습니다.

기타

이 프로그램은 자막 도구·모델 설치와 Google 번역 외에 인터넷을 사용하지 않습니다.

소스는 GitHub에 공개되어 있습니다. 오픈소스이므로 직접 코드를 다운받아서 GPT한테 분석해달라고 하셔도 됩니다.

02 / 저장과 인터넷 사용

파일 저장과 인터넷 사용

당연히 회원가입 없이 사용할 수 있습니다. 영상과 시청 기록을 운영자에게 보내지 않으며, 사용 내역이나 오류 보고도 자동으로 보내지 않습니다. 필요한 도구를 내려받거나 Google 번역을 사용할 때는 인터넷을 사용합니다.

영상 관리·재생

처리 위치
사용자 PC
처리 내용
영상 목록, 별점, 메모, 시청 기록, 하이라이트와 썸네일은 내 PC에 저장합니다. 앱 운영자에게 보내지 않습니다.

AI 음성 인식

처리 위치
내 PC의 그래픽카드 · Whisper
처리 내용
영상 속 말소리를 내 PC에서 분석해 자막을 만듭니다. 영상이나 음성을 외부 음성 인식 서비스로 보내지 않습니다. 필요한 모델을 내려받은 뒤에는 인터넷 없이 자막을 만들 수 있습니다.

내 PC에서 한국어 번역

처리 위치
내 PC · WSL의 Ollama
처리 내용
내 PC에 설치한 Ollama와 qwen3:8b 모델로 자막을 번역합니다. 설치를 마친 뒤에는 인터넷 없이 사용할 수 있습니다.

Google Cloud 번역

사용 조건
API 키를 등록하고 사용 설정을 켰을 때만 사용
전송 내용
번역할 자막 문장, 언어와 번역 설정, API 키를 Google에 보냅니다. 영상·음성 파일과 파일 경로는 보내지 않습니다. Google의 사용 요금이 발생할 수 있습니다.

자막에 필요한 도구 설치

사용 시점
자동 설치를 누르거나, 아직 없는 음성 인식 모델을 처음 사용할 때
다운로드
Microsoft, Ubuntu, Python, Hugging Face, Ollama의 배포처에서 필요한 프로그램과 모델을 내려받습니다. 이때 영상이나 자막 내용은 보내지 않습니다.

파일이 저장되는 곳

영상 목록과 설정, 썸네일, 재생용 임시 파일, 진행 중인 자막 작업은 %APPDATA%\dark-video-manager에 저장합니다. 완성된 SRT 자막은 영상과 같은 폴더에 저장합니다.

저장한 자료의 보호

Google API 키는 Windows의 보안 기능으로 암호화해 저장합니다. 영상 정보, 일반 설정, 영상, 자막과 임시 파일은 앱에서 암호화하지 않습니다. OneDrive 같은 동기화 폴더에 둔 자료는 해당 서비스 설정에 따라 온라인이나 다른 기기에도 저장될 수 있습니다.

데모에서 바꾼 내용

데모에서 바꾼 별점과 메모, 저장한 하이라이트와 캡처, 자막 체험 기록은 현재 브라우저에 저장됩니다. Windows 앱과 연결되지 않습니다. 브라우저에서 이 사이트의 데이터를 지우면 체험 기록도 삭제됩니다.

Google 번역을 끄거나 키, 사용 한도, 연결 문제로 사용할 수 없으면 내 PC에 준비된 Ollama로 번역합니다. 이 번역도 실패하면 원래 언어의 자막은 남겨 두고 오류를 표시합니다. 앱에 설정한 문자 한도만으로 Google 계정 전체의 요금을 막을 수는 없습니다.

03 / 설치 방법

설치 방법과 필요한 PC 환경

영상 관리와 재생은 AI 도구나 API 키 없이 사용할 수 있습니다. AI로 자막을 만들고 한국어로 번역하려면 필요한 도구를 추가로 설치합니다.

설치 순서

  1. 앱 실행

    아래에서 설치 파일을 내려받아 실행하고 설치 안내를 따릅니다. 설치 없이 사용하려면 포터블 파일을 실행합니다. 업데이트 전에는 작업 표시줄의 작은 아이콘(트레이) 메뉴에서 앱을 완전히 종료합니다.

  2. 라이브러리 등록

    동영상이 있는 폴더를 등록합니다. 목록에서 영상을 재생하고 제목, 태그, 별점과 메모를 입력할 수 있습니다. 자막을 만들려면 영상 폴더에 새 파일을 저장할 수 있어야 합니다.

  3. 자막 환경 자동 설치

    자막 생성 → 자막 환경 자동 설치에서 설치를 시작합니다. 기본 음성 인식 모델(base)과 번역에 필요한 도구를 준비합니다. 이미 사용할 수 있는 도구와 모델은 다시 설치하지 않습니다.

  4. 설치를 마친 뒤 자막 만들기

    Windows에서 관리자 승인이나 재시작을 요청할 수 있습니다. 재시작했다면 앱을 다시 열고 설치 버튼을 눌러 이어서 진행합니다. 준비가 끝나면 영상의 AI 자막 생성에서 모델, 영상 언어, 한국어 번역 여부를 고릅니다.

필요한 PC 환경

운영체제
Windows 10 또는 11 · 64비트(x64)
음성 인식
Vulkan을 지원하는 그래픽카드가 필요합니다. 그래픽 드라이버는 별도로 설치해야 합니다. 그래픽카드를 사용할 수 없으면 CPU로 바꾸어 진행하지 않고 오류를 표시합니다.
내 PC에서 번역
Windows에서 Linux 도구를 실행하는 WSL Ubuntu와 Python, Ollama, qwen3:8b가 필요합니다. 자막 환경 자동 설치에서 준비하며, 기본 Ubuntu 버전은 24.04입니다.
설치 공간
처음 AI 도구를 설치할 때 15 GB 이상의 여유 공간을 권장합니다. 큰 모델을 선택하거나 재생용 임시 파일이 늘어나면 공간이 더 필요합니다.
인터넷
도구와 모델을 내려받거나 Google 번역을 사용할 때 필요합니다. 설치를 마친 음성 인식과 내 PC에서 하는 번역은 인터넷 없이 사용할 수 있습니다.
도구가 없을 때
일반 자막 생성 화면에서는 Ollama와 번역 모델을 새로 설치하지 않습니다. 필요한 도구가 없다는 안내가 나오면 자막 환경 자동 설치를 실행합니다.

테스트한 환경

WSL이 없는 새 Windows 11 가상 PC에서 설치와 재시작 후 준비 상태를 확인했습니다. 그래픽카드를 이용한 자막 생성과 한국어 번역은 별도 PC에서 확인했습니다. Windows 10과 모든 그래픽카드·드라이버 조합을 시험한 것은 아닙니다.

GOOD TO KNOW

궁금한 점, 먼저 확인하세요.

인터넷 없이도 사용할 수 있나요?+

일반 영상 관리·재생·하이라이트는 로컬에서 사용합니다. AI 도구와 모델을 처음 준비할 때는 인터넷이 필요합니다. 모델 준비 후 원어 자막 생성과 준비된 Ollama를 이용한 로컬 번역은 로컬에서 처리하며, Google Cloud 번역은 인터넷이 필요합니다.

AI 자막을 생성하는 동안 다른 작업도 할 수 있나요?+

네. 자막 생성 중에도 하이라이트와 썸네일을 저장할 수 있습니다. 자막 작업은 대기열에서 관리하며 일시정지와 재개를 지원합니다.

영상이나 자막을 외부로 전송하나요?+

앱은 운영자 서버에 영상을 업로드하지 않습니다. 음성 인식과 로컬 번역은 PC에서 처리합니다. Google Cloud Translation을 직접 켠 경우에는 번역할 자막 텍스트가 Google에 전송되며 비용이 발생할 수 있습니다. 앱 데이터는 암호화 보관함이 아니며, OneDrive 등 동기화 폴더는 해당 서비스 설정을 따릅니다.

오픈소스로 공개되나요?+

자체 코드와 아이콘은 GitHub에서 MIT 라이선스로 공개합니다. 설치 파일과 대응 소스는 GitHub Releases에서 받을 수 있습니다. 포함된 외부 구성 요소는 각각의 라이선스를 따르며, FFmpeg·x264 등에는 별도의 GPL 조건이 적용됩니다.

Mac이나 Linux에서도 사용할 수 있나요?+

현재 지원 대상은 Windows 10/11 x64입니다. AI 음성 인식에는 Vulkan을 지원하는 GPU가 필요하며, 로컬 번역 환경은 WSL Ubuntu를 사용합니다.
