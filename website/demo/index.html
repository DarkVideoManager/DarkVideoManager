실제 앱의 화면으로 체험해 보세요.

영상 카드를 한 번 누르면 상세 정보, 두 번 누르면 플레이어를 엽니다. 위의 ‘선택한 영상 재생’ 버튼으로도 열 수 있습니다.

  • 검색과 ‘자막 없음’ 필터로 영상을 찾으세요.
  • W로 재생·일시정지, A/D로 1초 뒤로·앞으로 이동하고 S로 하이라이트를 저장하세요. Shift+A/D는 5초 이동합니다. 한글 키보드에서도 사용할 수 있습니다.
  • Q/E로 이전·다음 하이라이트, Z/C로 이전·다음 자막을 이동하세요. 화면의 키 버튼으로도 사용할 수 있습니다.
  • Space로도 재생하고, H로 하이라이트를 추가하세요. F 또는 T로 현재 장면을 썸네일로 저장합니다.
  • 오른쪽 ‘자막 탐색’ 탭에서 문장을 누르면 해당 시점으로 이동합니다.
  • ‘자막 생성 체험’에서 영상을 선택하고 진행률·일시정지·재개를 체험하세요. 완료하면 자막을 탐색할 수 있습니다.
  • 통계에는 미리 준비한 예시 시청 기록과 직접 재생한 기록이 함께 표시됩니다.
  • 별점·메모·하이라이트·캡처한 썸네일·체험 자막은 이 브라우저에 저장됩니다.

샘플 자막은 수작업으로 작성한 장면 설명입니다. 브라우저의 자막 생성은 이 자막으로 진행 과정을 재현하는 시뮬레이션입니다. 실제 AI 음성 인식·환경 설치·PC 폴더 접근은 Windows 앱에서 제공합니다.

‘체험 초기화’는 이 데모에 저장한 변경사항만 초기 상태로 되돌립니다.
